## How it works

1. **Choose a workflow.** Start from a prompt, an image, or a ready-made effect.
2. **Add your idea.** Enter a prompt or upload the photos requested by the tool.
3. **Review and generate.** Check the Credits required before submitting. View finished creations in IKAT.
