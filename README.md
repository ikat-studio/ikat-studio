# IKAT AI

**AI Video & Image Generator**

IKAT is an online creative studio for turning text prompts and photos into AI videos, creating images, and exploring ready-made AI effects. Choose a workflow, review the Credit cost, and create in your browser.

**[Create with IKAT](https://ikat.app/?utm_source=github&utm_medium=social&utm_campaign=github_profile&utm_content=readme_home)** · **[Explore AI Effects](https://ikat.app/effects?utm_source=github&utm_medium=social&utm_campaign=github_profile&utm_content=readme_effects)**

## What you can create

| Workflow | What it does |
| --- | --- |
| [Text to Video](https://ikat.app/text-to-video?utm_source=github&utm_medium=social&utm_campaign=github_profile&utm_content=readme_text_to_video) | Describe a scene, action, and camera movement to generate a video. |
| [Image to Video](https://ikat.app/image-to-video?utm_source=github&utm_medium=social&utm_campaign=github_profile&utm_content=readme_image_to_video) | Animate a photo or still image with a motion prompt. |
| [Text to Image](https://ikat.app/image/text-to-image?utm_source=github&utm_medium=social&utm_campaign=github_profile&utm_content=readme_text_to_image) | Create images from written descriptions. |
| [Image to Image](https://ikat.app/image/image-to-image?utm_source=github&utm_medium=social&utm_campaign=github_profile&utm_content=readme_image_to_image) | Edit an existing image using natural-language instructions. |
| [AI Effects](https://ikat.app/effects?utm_source=github&utm_medium=social&utm_campaign=github_profile&utm_content=readme_effects_table) | Try ready-made photo and video effects with your own images. |

## How it works

1. **Start with a prompt or photo.** Choose text-to-video, image-to-video, or an image workflow.
2. **Choose a model or effect.** The available options depend on the workflow.
3. **Review the Credit cost and generate.** View your creations in IKAT when they're ready.

## About this GitHub

This profile is the home for IKAT's public creative examples and developer-facing resources. The generation tools run on the IKAT website; you don't need to install anything from GitHub to try them.
